## Recaptcha, but make it a game
This started as a joke about boring captcha flows.

Instead of ticking boxes, the form opens a small pixel art scene and you have to click the character you’re asked for. It keeps the same job as a bot check in spirit, but the interaction is a bit silly and a lot more fun to record.
