Arrays are one of the most used structures in all of JavaScript. They're the digital shoebox we toss our items into — whether that’s numbers, strings, objects, or more arrays.

This cheatsheet walks you through every core array method — with simple examples and short explanations.

## Access & Info
`.length`
Returns the number of elements.

`.includes(value)`
Checks if a value exists.

## Push

Add to the end the end of the array.

<PushDemo />

.pop()
Removes the last item.

<CodeBlock lang="js"> {`const arr = [1, 2, 3]; arr.pop(); // [1, 2]`} </CodeBlock>
.unshift(value)
Adds to the start.

<CodeBlock lang="js"> {`const arr = [2, 3]; arr.unshift(1); // [1, 2, 3]`} </CodeBlock>
.shift()
Removes the first item.

<CodeBlock lang="js"> {`const arr = [1, 2, 3]; arr.shift(); // [2, 3]`} </CodeBlock>
🔁 Transform & Iterate
.map(fn)
Returns a new array with each item transformed.

<CodeBlock lang="js"> {`[1, 2, 3].map(n => n * 2) // [2, 4, 6]`} </CodeBlock>
.filter(fn)
Keeps only items that pass a test.

<CodeBlock lang="js"> {`[1, 2, 3, 4].filter(n => n > 2) // [3, 4]`} </CodeBlock>
.reduce(fn, initial)
Combines all items into a single value.

<CodeBlock lang="js"> {`[1, 2, 3].reduce((sum, n) => sum + n, 0) // 6`} </CodeBlock>
🔎 Search & Check
.find(fn)
Finds the first matching value.

<CodeBlock lang="js"> {`[1, 2, 3].find(n => n > 1) // 2`} </CodeBlock>
.some(fn)
Returns true if any match.

<CodeBlock lang="js"> {`[1, 2, 3].some(n => n > 2) // true`} </CodeBlock>
.every(fn)
Returns true if all match.

<CodeBlock lang="js"> {`[1, 2, 3].every(n => n > 0) // true`} </CodeBlock>
🔄 Reorder
.sort(fn)
Sorts items in place.

<CodeBlock lang="js"> {`[3, 1, 2].sort((a, b) => a - b) // [1, 2, 3]`} </CodeBlock>
.reverse()
Reverses the array in place.

<CodeBlock lang="js"> {`[1, 2, 3].reverse() // [3, 2, 1]`} </CodeBlock>
🧪 Slice, Splice, Flat
.slice(start, end)
Returns a shallow copy.

<CodeBlock lang="js"> {`[0, 1, 2, 3].slice(1, 3) // [1, 2]`} </CodeBlock>
.splice(start, deleteCount, ...items)
Adds/removes items at a position.

<CodeBlock lang="js"> {`let a = [1, 2, 3]; a.splice(1, 1, 99); // [1, 99, 3]`} </CodeBlock>
.flat(depth)
Flattens nested arrays.

<CodeBlock lang="js"> {`[1, [2, [3]]].flat(2) // [1, 2, 3]`} </CodeBlock>
🧵 Create & Combine
.concat()
Merges arrays together.

<CodeBlock lang="js"> {`[1, 2].concat([3, 4]) // [1, 2, 3, 4]`} </CodeBlock>
.join(sep)
Turns array into string.

<CodeBlock lang="js"> {`['a', 'b'].join('-') // 'a-b'`} </CodeBlock>
Array.from()
Creates array from iterable.

<CodeBlock lang="js"> {`Array.from('hi') // ['h', 'i']`} </CodeBlock>
